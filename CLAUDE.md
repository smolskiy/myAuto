# Мой авто

Личная PWA для полной истории машин: ТО и ремонты (работы, запчасти с брендом и артикулом, СТО, мастер),
заправки, расходы, напоминания, фото, документы, шины. Данные — IndexedDB (Dexie), синхронизация — папка
приложения на Яндекс.Диске, хостинг — GitHub Pages. Владелец общается по-русски; интерфейс — только русский.

- Спецификация (источник истины): `docs/superpowers/specs/2026-09-25-myauto-design.md`
- Планы по волнам и кто что делает: `docs/superpowers/plans/README.md`

## Проверка перед каждым коммитом

`npm run typecheck && npm run lint && npm test` — всё зелёное. Экраны и навигация — ещё `npm run test:e2e`.
Новую логику пишем от падающего теста (red → green).

## Границы слоёв

`domain/` — чистый TS, без импортов из других слоёв. `db/` → только `domain/`. `sync/` → `domain/`, `db/`.
`ui/` — изолирован: данные и готовые строки приходят пропсами. `features/` и `app/` собирают всё.
ESLint (`no-restricted-imports` в `eslint.config.js`) валит сборку при нарушении.

## Замороженные контракты

`src/domain/types.ts`, `src/domain/snapshot.ts`, `src/sync/contracts.ts`, `src/db/schema.ts` меняет только лидер.
Агенту нужен другой контракт — он описывает изменение и причину в отчёте и работает с текущим.

## Соглашения, которых не видно из конфигов

- Деньги — целые копейки (`Kopecks`); пробег — целые км; даты — строка `YYYY-MM-DD`; `today` передаётся параметром.
- Числа для людей: разряды и пробел перед единицей — неразрывный пробел U+00A0 («148 320 км», «12 450 ₽»).
- Удаление всегда мягкое (`deleted: true`); все правки строк — через репозитории `src/db/repos.ts`
  (они ставят строго растущий `updatedAt` через `tick()` и сообщают синхронизации об изменении).
- `Draft<T>` / `Patch<T>` распределяются по объединению `CarRecord` — черновик записи ТО несёт свои поля.
- Зависимости поставлены в волне 0; новый npm-пакет добавляет только лидер.
- Тексты интерфейса — короткие, без «успешно» и восклицаний.

## Git

Коммит на каждую задачу плана, conventional commits, `git add` по конкретным путям.
Последняя строка сообщения: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
Агенты волн работают в своём worktree и своей ветке; сливает в `main` лидер после ревью.

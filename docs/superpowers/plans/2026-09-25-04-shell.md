# Волна 2a · оболочка и общие части экранов: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Всё, что нужно трём параллельным агентам экранов (волна 2b), чтобы не ждать друг друга: запуск приложения
(сид каталога, синхронизация, тост обновления), оболочка с нижней панелью и кнопкой «+», каркас страницы, подписи и
значки записей, общие поля (вложения, выбор места/мастера), удаление с «Отменить», «сегодня», первый запуск.

**Architecture:** `src/app/**` — запуск и оболочка; `src/features/common/**` — общие для экранов компоненты и функции.
Экраны волны 2b импортируют только отсюда, из `src/ui`, `src/db/hooks.ts`, `src/db/repos.ts`, `src/domain/**`, `src/sync/index.ts|react.ts`.

**Tech Stack:** React 19, React Router 8 (hash), Testing Library + fake-indexeddb, компоненты `src/ui`, хуки `src/db/hooks.ts`.

**Spec:** `docs/superpowers/specs/2026-09-25-myauto-design.md` (разделы 7, 7.1, 8)

**Зона агента:** `src/app/**`, `src/features/common/**`, `src/main.tsx`. Страницы `src/features/<экран>/` не трогать
(кроме удаления тестового заголовка в `routes`-тесте, см. Task 2).

## Global Constraints

- Весь текст — по-русски; числа и даты — только через `src/domain/format.ts`.
- `ui/` получает готовые строки: форматирование делается здесь, а не в компонентах.
- Нижняя панель видна на корневых разделах (`/`, `/journal`, `/reminders`, `/more` и страницах разделов «Ещё»);
  на формах (`/record/new/*`, `*/edit`, `/vehicle/new`, `/reminders/new`, `/documents/new`, `/tires/new`,
  `/places/new`, `/masters/new`, `/onboarding`) — скрыта, у формы своя шапка «Назад / Сохранить».
- Проверка перед коммитом: `npm run typecheck && npm run lint && npm test`.

## Review Focus

1. **Первый запуск без машин** — любой экран, кроме `/onboarding`, `/showcase`, `/settings/*`, ведёт на онбординг; после
   добавления машины редиректа больше нет. Тест — Task 2.
2. **Отмена новой записи с уже добавленным фото** — вложения, созданные до сохранения, удаляются. Тест — Task 4.
3. **«Отменить» после удаления** — восстанавливает ту же строку (тот же id), тост исчезает через 5 с. Тест — Task 3.
4. **Новая версия приложения** — тост «Доступна новая версия» с кнопкой «Обновить», вызывающей обновление SW. Тест — Task 2.
5. **Полночь** — `useToday()` отдаёт новую дату после возврата в приложение на следующий день. Тест — Task 3.

### Task 1: Запуск приложения

**Files:** Create `src/app/init.ts`, `src/app/init.test.ts`; Modify `src/main.tsx`

**Interfaces:**
- Consumes: `ensureSeed` (`db/seed.ts`), `BUILTIN_CATALOG` (`domain/catalog.ts`), `db`, `initSync` (`sync/index.ts`).
- Produces: `initApp(deps?: { db?: MyAutoDB; initSync?: () => Promise<void> }): Promise<void>` — сид каталога, затем
  `initSync()`; ошибки синхронизации не мешают запуску (`console.warn`). `main.tsx` вызывает `initApp()` до рендера,
  не блокируя его дольше сида (синхронизация — без `await`).

- [ ] **Step 1: Падающий тест**

```ts
import { afterEach, expect, test, vi } from 'vitest'
import { MyAutoDB } from '../db/schema'
import { BUILTIN_CATALOG } from '../domain/catalog'
import { initApp } from './init'

const db = new MyAutoDB(`t-${crypto.randomUUID()}`)
afterEach(async () => { await db.catalogItems.clear() })

test('засевает каталог и запускает синхронизацию', async () => {
  const initSync = vi.fn(async () => {})
  await initApp({ db, initSync })
  expect(await db.catalogItems.count()).toBe(BUILTIN_CATALOG.length)
  expect(initSync).toHaveBeenCalledOnce()
})

test('сбой синхронизации не ломает запуск', async () => {
  vi.spyOn(console, 'warn').mockImplementation(() => {})
  await expect(initApp({ db, initSync: async () => { throw new Error('нет сети') } })).resolves.toBeUndefined()
})
```

### Task 2: Оболочка — нижняя панель, «+», первый запуск, тост обновления

**Files:** Modify `src/app/AppShell.tsx`, `src/app/routes.tsx`, `src/app/router.test.tsx`; Create `src/app/AppShell.test.tsx`,
`src/app/AddRecordSheet.tsx`, `src/app/useFirstRunRedirect.ts`, `src/app/useUpdateToast.ts`, `src/app/providers.tsx`, `src/app/ErrorPage.tsx`

**Interfaces:**
- Consumes: `BottomTabBar`, `ActionSheet`, `ToastProvider`, `useToast`, `Icon` из `src/ui`; `useVehicles` из `db/hooks.ts`.
- Produces:
  - `AppProviders({ children })` — `ToastProvider` (ThemeProvider уже в `main.tsx`)
  - `AppShell` — `<Outlet />` + `BottomTabBar` (Главная `/`, Журнал `/journal`, ТО `/reminders`, Ещё `/more`; «+» открывает
    `AddRecordSheet`); панель скрыта на маршрутах форм (Global Constraints)
  - `AddRecordSheet({ open, onClose })` — 5 действий в порядке: «ТО и ремонт» → `/record/new/service`, «Заправка» → `fuel`,
    «Расход» → `expense`, «Пробег» → `odometer`, «Заметка» → `note`
  - `useFirstRunRedirect()` — если `useVehicles()` вернул `[]` и путь не `/onboarding`, `/showcase`, `/settings*` → `navigate('/onboarding', { replace: true })`
  - `useUpdateToast()` — слушает `window` `pwa:need-refresh`, показывает тост «Доступна новая версия» с действием «Обновить» → `detail.update()`
  - `ErrorPage` (`src/app/ErrorPage.tsx`) — `errorElement` корневого маршрута в `routes.tsx`: «Что-то пошло не так»,
    текст ошибки мелко, кнопки «Перезагрузить» (`location.reload()`) и «На главную»; ошибка загрузки чанка после обновления
    приложения («Failed to fetch dynamically imported module») — один автоматический `location.reload()`
    (флаг в `sessionStorage`, чтобы не зациклиться). Заменяет английскую страницу ошибки React Router.
    Тест: маршрут, чей компонент бросает исключение, показывает «Что-то пошло не так».

- [ ] **Step 1: Падающие тесты** — `src/app/AppShell.test.tsx`:

```tsx
import { render, screen, waitFor, act } from '@testing-library/react'
import userEvent from '@testing-library/user-event'
import { RouterProvider } from 'react-router'
import { afterEach, beforeEach, expect, test, vi } from 'vitest'
import { db } from '../db/instance'
import { repos } from '../db/repos'
import { createAppRouter } from './routes'
import { AppProviders } from './providers'

const renderAt = (path: string) => {
  const router = createAppRouter({ initialPath: path })
  render(<AppProviders><RouterProvider router={router} /></AppProviders>)
  return router
}
const addVehicle = () => repos.vehicles.create({ name: 'Октавия', make: 'Skoda', model: 'Octavia', archived: false, fluids: [], order: 0 })

beforeEach(async () => { await db.open() })
afterEach(async () => { await Promise.all(db.tables.map((t) => t.clear())) })

test('кнопка «+» открывает выбор типа записи и ведёт в форму заправки', async () => {
  await addVehicle()
  const router = renderAt('/')
  await userEvent.click(await screen.findByRole('button', { name: 'Добавить запись' }))
  const names = screen.getAllByRole('menuitem').map((b) => b.textContent)
  expect(names).toEqual(['ТО и ремонт', 'Заправка', 'Расход', 'Пробег', 'Заметка'])
  await userEvent.click(screen.getByRole('menuitem', { name: 'Заправка' }))
  await waitFor(() => expect(router.state.location.pathname).toBe('/record/new/fuel'))
})

test('на формах нижней панели нет', async () => {
  await addVehicle()
  renderAt('/record/new/fuel')
  await waitFor(() => expect(screen.queryByRole('button', { name: 'Добавить запись' })).not.toBeInTheDocument())
})

test('без машин — онбординг; с машиной — без редиректа', async () => {
  const router = renderAt('/journal')
  await waitFor(() => expect(router.state.location.pathname).toBe('/onboarding'))
})

test('настройки доступны и без машин', async () => {
  const router = renderAt('/settings/sync')
  await new Promise((r) => setTimeout(r, 50))
  expect(router.state.location.pathname).toBe('/settings/sync')
})

test('тост новой версии обновляет приложение', async () => {
  await addVehicle()
  renderAt('/')
  const update = vi.fn()
  act(() => { window.dispatchEvent(new CustomEvent('pwa:need-refresh', { detail: { update } })) })
  await userEvent.click(await screen.findByRole('button', { name: 'Обновить' }))
  expect(update).toHaveBeenCalled()
})
```

### Task 3: Общие хуки и функции

**Files:** Create `src/features/common/useToday.ts`, `src/features/common/useSoftDelete.ts`, `src/features/common/useLookup.ts`,
`src/features/common/labels.ts`, `src/features/common/recordPresentation.tsx`, `src/features/common/common.test.tsx`

**Interfaces:**
- Produces:
  - `useToday(): ISODate` — `todayISO()`, пересчитывается на `visibilitychange` (visible) и раз в минуту
  - `useSoftDelete(): (opts: { remove(): Promise<void>; restore(): Promise<void>; text: string /* «Запись удалена» */ }) => Promise<void>` —
    удаляет и показывает тост с «Отменить» → `restore()`
  - `useLookup(): { places: Map<ID, Place>; masters: Map<ID, Master>; catalog: Map<ID, CatalogItem> } | undefined`
  - `labels.ts`: `RECORD_KIND_LABELS: Record<RecordKind, string>` (ТО и ремонт, Заправка, Расход, Пробег, Заметка),
    `SERVICE_TYPE_LABELS` (maintenance «ТО», repair «Ремонт», diagnostics «Диагностика», bodywork «Кузов», tires «Шины»,
    tuning «Тюнинг», other «Другое»), `EXPENSE_CATEGORY_LABELS` (= `COST_GROUP_LABELS` из `domain/calc/costs.ts` для категорий),
    `PLACE_KIND_LABELS` (service «СТО», fuel «АЗС», parts «Магазин запчастей», wash «Мойка», tire «Шиномонтаж»,
    insurance «Страховая», other «Другое»), `FUEL_TYPE_LABELS`, `TRANSMISSION_LABELS` (mt «Механика», at «Автомат»,
    cvt «Вариатор», amt «Робот», dct «Робот с двумя сцеплениями»), `DRIVE_LABELS` (fwd «Передний», rwd «Задний», awd «Полный»),
    `FLUID_KIND_LABELS`, `UNIT_LABELS` (pcs «шт», l «л», set «компл.», m «м», kg «кг»), `TIRE_SEASON_LABELS`, `TIRE_STATUS_LABELS`
  - `recordPresentation.tsx`: `RECORD_KIND_ICON: Record<RecordKind, TablerIcon>` (tool, gas-station, receipt, gauge, note),
    `recordTitle(r: CarRecord): string` (service → `title`; fuel → `Заправка · 42,5 л`; expense → `title` или метка категории;
    odometer → «Пробег»; note → `title`), `recordSubtitle(r: CarRecord, lookup): string` (`148 320 км · Автосервис`,
    части без значения пропускаются), `recordRowProps(r, lookup): RecordRowProps` (для `RecordRow` из `src/ui`)

- [ ] **Step 1: Падающие тесты** — `common.test.tsx`: `recordTitle` для всех 5 видов; `recordSubtitle` с местом и без
  пробега; `useSoftDelete` — удаление → тост «Запись удалена» → «Отменить» вызывает `restore`; `useToday` меняется после
  `vi.setSystemTime(следующий день)` + `document.dispatchEvent(new Event('visibilitychange'))`.

```tsx
import { expect, test } from 'vitest'
import { NBSP } from '../../domain/format'
import { recordTitle, recordSubtitle } from './recordPresentation'
import { fuel, expense, service, odo, note } from '../../domain/calc/fixtures'

const lookup = { places: new Map([['pl', { id: 'pl', createdAt: 1, updatedAt: 1, kind: 'service' as const, name: 'Автосервис' }]]), masters: new Map(), catalog: new Map() }

test('заголовки записей', () => {
  expect(recordTitle(service({ title: 'ТО-15' }))).toBe('ТО-15')
  expect(recordTitle(fuel({ liters: 42.5 }))).toBe(`Заправка · 42,5${NBSP}л`)
  expect(recordTitle(expense({ category: 'osago' }))).toBe('ОСАГО')
  expect(recordTitle(expense({ category: 'wash', title: 'Мойка у дома' }))).toBe('Мойка у дома')
  expect(recordTitle(odo({}))).toBe('Пробег')
  expect(recordTitle(note({ title: 'Стук справа' }))).toBe('Стук справа')
})

test('подзаголовок: пробег и место', () => {
  expect(recordSubtitle(service({ odometer: 148320, placeId: 'pl' }), lookup)).toBe(`148${NBSP}320${NBSP}км · Автосервис`)
  expect(recordSubtitle(note({ title: 'x' }), lookup)).toBe('')
})
```

### Task 4: Общие компоненты экранов

**Files:** Create `src/features/common/Page.tsx`, `src/features/common/FormPage.tsx`, `src/features/common/VehicleGate.tsx`,
`src/features/common/AttachmentsField.tsx`, `src/features/common/PlacePicker.tsx`, `src/features/common/MasterPicker.tsx`,
`src/features/common/CatalogItemPicker.tsx`, `src/features/common/components.test.tsx`, `src/features/common/index.ts`

**Interfaces:**
- Consumes: `AppBar`, `Combobox`, `AttachmentGrid`, `PhotoPicker`, `Lightbox`, `EmptyState`, `Button` из `src/ui`;
  `attachmentStore` (`sync/index.ts`), `useAttachmentUrl` (`sync/react.ts`); хуки `usePlaces`, `useMasters`, `useCatalog`,
  `useAttachments`, `useActiveVehicle`; `repos`.
- Produces (всё реэкспортируется из `src/features/common/index.ts`):
  - `Page({ title, back?: boolean | string, actions?, large?, children })` — `AppBar` + контейнер с отступами и safe-area;
    `back: true` → `navigate(-1)`, строка → `navigate(путь)`
  - `FormPage({ title, onSave(): Promise<void>, saveLabel?: 'Сохранить', onCancel?(): void, children, saving?: boolean })` —
    шапка «Назад» + «Сохранить»; ошибка из `onSave` показывается тостом, форма остаётся открытой
  - `VehicleGate({ children: (vehicle: Vehicle) => ReactNode })` — нет активной машины → `EmptyState` «Добавьте машину»
    с кнопкой → `/vehicle/new`
  - `AttachmentsField({ ownerType, ownerId, label?: 'Фото и документы' })` — сетка превью (`useAttachmentUrl(att, 'thumb')`),
    «Добавить фото», просмотр в `Lightbox`, удаление; ошибки `addFile` — тостом
  - `useDraftAttachments(ownerType)` → `{ ownerId: ID; discard(): Promise<void> }` — id для ещё не сохранённой записи;
    `discard` удаляет вложения, добавленные к этому id (вызывается при отмене формы)
  - `PlacePicker({ label, kinds: PlaceKind[], value?: ID, onChange(id?: ID): void })` — комбобокс мест с созданием нового
    (`repos.places.create({ kind: kinds[0], name })`)
  - `MasterPicker({ placeId?: ID, value?: ID, onChange(id?: ID): void })` — мастера места (или все, если места нет), создание нового
  - `CatalogItemPicker({ label?: 'Узел', value?: ID, onChange(id?: ID, item?: CatalogItem): void })` — поиск по каталогу, группы в подсказке

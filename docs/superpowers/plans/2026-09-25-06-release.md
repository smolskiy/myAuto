# Волна 3 · интеграция, сквозные сценарии, выпуск: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать всё в `main`, доказать сквозными e2e-сценариями из спецификации (раздел 10), что приложение работает
как единое целое офлайн и после перезагрузки, закрыть отложенные мелочи из журналов ревью, выложить на GitHub Pages.

**Architecture:** Ветки треков экранов сливаются лидером; агент `qa-release` пишет e2e по шагам владельца; найденные дефекты
чинит агент `feature-screens` (или слой-владелец) по отчёту. Выпуск — GitHub Actions → Pages.

**Spec:** `docs/superpowers/specs/2026-09-25-myauto-design.md` (разделы 1, 9, 10)

## Global Constraints

- Сценарии e2e — по ролям и русским подписям, вьюпорт 390×844, Chromium; без привязки к CSS-классам.
- Проверка перед выпуском: `npm run typecheck && npm run lint && npm test && npm run build && npm run test:e2e`.
- Публикация (создание публичного репозитория, включение Pages, push) — только после «да» владельца в чате.

## Review Focus

1. **Перезагрузка без сети** — после установки SW приложение открывается офлайн, данные на месте. Тест — Task 2.
2. **Сборка с `base: /myAuto/`** — SW, манифест и `oauth.html` работают из подпапки. Тест — Task 3.
3. **Две вкладки** — синхронизация не идёт в двух вкладках одновременно (Web Locks). Живая проверка — Task 5.
4. **Первый запуск на телефоне** — онбординг → главная без белого экрана и мигания. Тест — Task 2.
5. **Импорт своего бэкапа на новом устройстве** — все записи и справочники на месте. Тест — Task 2.

### Task 2: Сквозные e2e-сценарии (агент `qa-release`)

**Files:** `e2e/helpers.ts`, `e2e/first-run.spec.ts`, `e2e/service-and-reminders.spec.ts`, `e2e/fuel.spec.ts`,
`e2e/offline.spec.ts`, `e2e/theme.spec.ts`, `e2e/backup.spec.ts`

- [ ] **first-run:** чистый профиль → онбординг → VIN `XTA210990Y2765432` → «Заполнить» даёт Lada/2000 → модель «2109»,
  пробег 148 000 → стартовые напоминания (все) → «Позже» → главная с карточкой машины и «Скоро».
- [ ] **service-and-reminders:** «+» → «ТО и ремонт» → название «ТО-15», место «Автосервис» (создать), 3 запчасти (масло
  Motul 4 л × 900 ₽, масляный фильтр Mann-Filter W 712/95 650 ₽, воздушный фильтр Mahle 1 200 ₽) → итог «5 450 ₽» →
  «Сохранить» → карточка записи с брендами и артикулом → главная: напоминание «Моторное масло» в порядке с остатком ≈ 10 000 км.
  Вторая запись ТО → узел «Масляный фильтр» показывает подсказку «В прошлый раз: Mann-Filter W 712/95, 650 ₽».
- [ ] **fuel:** две полные заправки (148 000 км 40 л; 148 500 км 38 л) → статистика/главная показывают расход «7,6 л/100 км».
- [ ] **offline:** после первого визита `context.setOffline(true)` → перезагрузка → главная и журнал с данными.
- [ ] **theme:** «Настройки → Тема → Тёмная» → `html[data-theme=dark]`, после перезагрузки сохраняется.
- [ ] **backup:** «Данные → Выгрузить копию» (перехват download) → очистить IndexedDB → онбординг → «Загрузить копию» с этим
  файлом → «Объединить» → записи на месте.
- [ ] Каждый красный сценарий — дефект в `docs/qa/2026-09-25-e2e.md` (шаги, ожидание, факт, скриншот, trace).

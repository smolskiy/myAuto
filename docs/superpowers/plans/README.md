**Порядок исполнения.** Волна 0 — лидер в основной ветке. Волна 1 — три агента параллельно, каждый в своём
git worktree и своей ветке (`wave1/domain-data`, `wave1/ui-system`, `wave1/sync-storage`); зоны файлов не пересекаются,
все зависимости поставлены в волне 0. Лидер ревьюит каждую ветку и сливает в `main`. Планы волны 2 написаны по
интерфейсам из планов волны 1 и сверяются с отчётами агентов (отклонения) перед запуском; волна 2b — три агента параллельно.
План волны 3 пишется после слияния волны 2.

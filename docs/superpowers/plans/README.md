# Планы «Мой авто»

Спецификация: [../specs/2026-09-25-myauto-design.md](../specs/2026-09-25-myauto-design.md)

| Волна | План | Кто выполняет | Зависит от |
|---|---|---|---|
| 0 | [00-foundation](2026-09-25-00-foundation.md) — каркас, контракты, даты/id/слияние, репозитории, маршруты, CI, агенты | лидер | — |
| 1 | [01-domain-data](2026-09-25-01-domain-data.md) — расчёты, каталог, бренды, VIN, `.ics`, хуки | агент `domain-data` | 0 |
| 1 | [02-ui-system](2026-09-25-02-ui-system.md) — токены, темы, компоненты, витрина, иконки | агент `ui-system` | 0 |
| 1 | [03-sync-storage](2026-09-25-03-sync-storage.md) — Диск, вход, синхронизация, фото, бэкапы, Excel | агент `sync-storage` | 0 |
| 2 | 04-screens-a / 04-screens-b — пишутся после слияния волны 1, по фактическим API хуков и компонентов | 2 × `feature-screens` | 1 |
| 3 | 05-release — подключение синхронизации к экранам, OAuth-приложение, репозиторий, деплой, e2e | лидер + `qa-release` | 2 |

**Порядок исполнения.** Волна 0 — лидер в основной ветке. Волна 1 — три агента параллельно, каждый в своём
git worktree и своей ветке (`wave1/domain-data`, `wave1/ui-system`, `wave1/sync-storage`); зоны файлов не пересекаются,
все зависимости поставлены в волне 0. Лидер ревьюит каждую ветку и сливает в `main`. Планы волн 2 и 3 пишутся
после слияния волны 1 — чтобы опираться на реальные сигнатуры, а не на догадки.

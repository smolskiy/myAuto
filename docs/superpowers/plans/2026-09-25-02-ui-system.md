# Волна 1 · ui-system — токены, темы, компоненты, витрина: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Перед началом загрузить скилл `frontend-design`.

**Goal:** Дизайн-система «Чистый системный» в двух темах: токены, тема с переключением, 45 компонентов с
данными только через пропсы и витрина `#/showcase`, где каждый компонент виден во всех состояниях в обеих темах.

**Architecture:** CSS-переменные в `src/ui/tokens.css` (светлая тема в `:root`, тёмная под `[data-theme="dark"]`),
`ThemeProvider` ставит `data-theme` на `<html>` и меняет `<meta name="theme-color">`. Компоненты — функциональные
React-компоненты + CSS Modules, без знания о базе и домене: всё форматирование приходит строками.
Публичный API — только через `src/ui/index.ts`.

**Tech Stack:** React 19, CSS Modules, `@tabler/icons-react`, `@fontsource/onest`, Recharts (только тема графиков),
Vitest + Testing Library, Playwright (скриншоты витрины для самопроверки).

**Spec:** `docs/superpowers/specs/2026-09-25-myauto-design.md` (разделы 7, 7.1, 8)

**Зона агента:** `src/ui/**`, `public/icons/**`, `index.html` (только `<meta>` и иконки), `vite.config.ts` (только
`manifest.icons`, `theme_color`, `background_color`). Не трогать `src/domain`, `src/db`, `src/sync`, `src/features`,
`src/app` (кроме того, что `/showcase` уже подключён к `src/ui/showcase/ShowcasePage.tsx`). Новых зависимостей не добавлять.

## Global Constraints

- `ui/` ничего не импортирует из `domain/ db/ sync/ features/ app/` (ESLint это проверяет).
- Все цвета, отступы, радиусы, тени, длительности — только через CSS-переменные из `tokens.css`; хардкод цвета в
  `.module.css` запрещён (кроме `tokens.css`).
- Контраст текста WCAG AA (≥ 4.5:1 для обычного текста, ≥ 3:1 для крупного и значков) в обеих темах; статусные цвета
  не единственный носитель смысла — рядом всегда текст или значок.
- Цель касания ≥ 44×44 px; видимый фокус (`:focus-visible`) у всех интерактивных элементов.
- `prefers-reduced-motion: reduce` отключает анимации переходов, сдвигов и «набегания».
- Тексты по умолчанию внутри компонентов — русские («Отменить», «Готово», «Ничего не найдено»), переопределяются пропсами.
- Числа в компонентах — `font-variant-numeric: tabular-nums`.
- Каждый компонент: `Name/Name.tsx`, `Name/Name.module.css`, экспорт из `src/ui/index.ts`, секция в витрине.

## Review Focus

1. **Тёмная тема на реальном телефоне** — `theme-color` в шапке браузера и фон `body` меняются вместе с темой,
   нет «белой вспышки» при загрузке (тема ставится до первого рендера). Тест — Task 1.
2. **Экранная клавиатура в шторке** — поле ввода в `BottomSheet` не закрывается клавиатурой (шторка ограничена
   `100dvh`, содержимое прокручивается). Проверка в витрине — Task 5.
3. **Длинные строки** (название СТО на 60 символов, артикул без пробелов) — не ломают строку списка, обрезаются
   многоточием, не выталкивают сумму. Тест — Task 3.
4. **MoneyField с выражением** («1200+650») — показывает результат, а в `onChange` уходит число, некорректное — сообщение.
   Тест — Task 4.
5. **Свайп на ПК мышью и на телефоне пальцем + доступность** — у `SwipeRow` есть альтернативные кнопки для клавиатуры
   и скринридера. Тест — Task 6.

- [ ] **Step 3: Падающий тест темы** — `src/ui/theme.test.tsx`:

```tsx
import { act, render, screen } from '@testing-library/react'
import { beforeEach, expect, test, vi } from 'vitest'
import { ThemeProvider, useTheme } from './theme'

function Probe() {
  const t = useTheme()
  return (
    <>
      <span data-testid="resolved">{t.resolved}</span>
      <button onClick={() => t.setPreference('dark')}>dark</button>
      <button onClick={() => t.setPreference('system')}>system</button>
    </>
  )
}

const mockSystem = (dark: boolean) => {
  const listeners: ((e: { matches: boolean }) => void)[] = []
  vi.stubGlobal('matchMedia', (q: string) => ({
    matches: q.includes('dark') ? dark : false, media: q,
    addEventListener: (_: string, l: (e: { matches: boolean }) => void) => listeners.push(l), removeEventListener: () => {},
  }))
  return (next: boolean) => listeners.forEach((l) => l({ matches: next }))
}

beforeEach(() => {
  localStorage.clear()
  document.head.innerHTML = '<meta name="theme-color" content="#F2F3F5">'
  document.documentElement.removeAttribute('data-theme')
})

test('по умолчанию — как в системе, и следит за её сменой', () => {
  const flip = mockSystem(false)
  render(<ThemeProvider><Probe /></ThemeProvider>)
  expect(screen.getByTestId('resolved').textContent).toBe('light')
  expect(document.documentElement.dataset.theme).toBe('light')
  act(() => flip(true))
  expect(document.documentElement.dataset.theme).toBe('dark')
})

test('ручной выбор сохраняется и меняет theme-color', () => {
  mockSystem(false)
  render(<ThemeProvider><Probe /></ThemeProvider>)
  act(() => screen.getByText('dark').click())
  expect(localStorage.getItem('myauto.theme')).toBe('dark')
  expect(document.documentElement.dataset.theme).toBe('dark')
  expect(document.querySelector('meta[name="theme-color"]')?.getAttribute('content')).toBe('#0E0F11')
  act(() => screen.getByText('system').click())
  expect(document.documentElement.dataset.theme).toBe('light')
})
```

## После выпуска · чертёж машины на главной

- Ruling: чертёж — картинки, сгенерированные владельцем в ChatGPT/Codex (белые линии на синем, 3/4 спереди слева), а не three.js — 3D-спайк (`myAuto-spikes/car-3d`) за два раунда не дал узнаваемой геометрии, картинки узнаются сразу — cost if wrong: новая модель требует генерации и ручной разметки зон (~30 мин).
- Ruling: из картинки делается маска линий (`tools/schematic-mask.py`), цвет даёт тема через `mask-image` — одна картинка на обе темы, ~200 КБ, в офлайн-кеше — cost if wrong: полутона исходника теряют цвет (линии одного тона).
- Ruling: скрытые узлы стоят там, где они у поперечного мотора: ГРМ и помпа — дальний край моторного отсека (со шкивами ремня), тормозная жидкость — бачок у стекла с «рентгеном» трубок к колёсам, антифриз — решётка, аккумулятор — у ближней фары; шины и подвеска — на переднем колесе — cost if wrong: точка не там, где узел у конкретного мотора; зона всё равно читается.
- Ruling: выноски прижаты к полям над и под машиной; вторая при столкновении уходит на другую сторону — поверх чертежа плашка закрывала решётку и фары, по которым машину узнают — cost if wrong: длинный поводок через бампер.
- Ruling: сопоставление модели мягкое — год и кузов проверяются, только если заполнены; cee'd без кузова считается универсалом — похожий чертёж лучше, чем никакого — cost if wrong: хэтчбек cee'd без указанного кузова покажется универсалом.

- Ruling (ревью): вторая выноска всегда на другой стороне — две плашки в одном поле налезали даже у далёких точек (оба колеса); подписи понимают кириллицу («Про Сид», «ИксСид», «Хэтчбэк», «А7»); срок в выноске — тот, что дал состояние (`stateKm`/`stateTime` в `ReminderStatus`); имя без проблем — «узлы в порядке» (документы в чертёж не входят); главная берёт «Скоро» и чертёж из одного запроса; запасные цвета для Safari без `color-mix` — cost if wrong: нет.
- Ruling (ревью, не делаем): обе картинки (~400 КБ) в офлайн-кеше у всех, а не по требованию — приложением пользуется владелец, у которого обе машины — cost if wrong: лишние 400 КБ при установке у человека без этих машин.
